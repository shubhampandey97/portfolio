# Shubham Pandey — Portfolio

Personal portfolio of **Shubham Pandey**, Data Scientist & Machine Learning Engineer.

**Live:** https://portfolio-eight-wine-rm1saozy1t.vercel.app/

## Sections
Hero · About · Skills · Experience · Projects · Certifications · Contact

## Built with
React 19 · Vite · Tailwind CSS 4 · Framer Motion · React Icons — deployed on Vercel.

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Editing content
All text content lives in `src/data/`:

| File | What it controls |
|---|---|
| `projects.js` | Project cards (`status: "In progress"` shows the amber badge; `demo` adds a Live Demo button) |
| `skills.js` | Skill groups (`inProgress: true` marks a group as currently building) |
| `experience.js` | Work experience |
| `certifications.js` | Certificates (`link` adds a "View certificate" button) |
